## Proyectos destacados

### Simulador de horarios universitarios

Aplicación web para ayudar a los estudiantes a planificar sus horarios antes de la inscripción de materias.

El proyecto nace de una necesidad cotidiana: la oferta de horarios suele entregarse como listados por materia, y muchos estudiantes recurren a Excel para visualizar cómo quedarían sus clases.

Desarrollé una herramienta que permite ingresar materias y horarios, construir una planificación manual o generar distintas combinaciones automáticamente. El estudiante puede comparar alternativas, identificar cruces, guardar opciones y descargar el horario que prefiera para utilizarlo como referencia al inscribir.

**Mi responsabilidad:** concepción, diseño y desarrollo completo del proyecto.

**Funcionalidades principales:**

- Registro de materias, secciones y sesiones de clase.
- Construcción manual de horarios.
- Generación automática de combinaciones.
- Detección de conflictos entre clases.
- Guardado de alternativas en el navegador.
- Descarga del horario seleccionado.

**Tecnologías:** HTML, CSS, JavaScript y almacenamiento local mediante `localStorage`.

**Estado:** versión inicial funcional, con planes de ampliar su alcance.

### DevReports

Plataforma para gestionar reportes HTML, usuarios y asignaciones a desarrolladores, con notificaciones por correo electrónico.

El proyecto apoya la organización del trabajo del equipo al reunir los reportes y sus responsables en una misma aplicación.

**Mi responsabilidad:** desarrollo integral de la interfaz, el backend, la persistencia y el despliegue.

**Aspectos técnicos destacados:**

- API modular con Node.js y Express.
- Frontend con HTML, CSS y JavaScript.
- Autenticación y control de acceso por roles.
- Migración de SQLite a PostgreSQL.
- Gestión de cambios de esquema mediante migraciones SQL.
- Respaldo y restauración de datos y archivos.
- Despliegue con Docker Compose y Dokploy.

**Tecnologías:** JavaScript, Node.js, Express, PostgreSQL, HTML, CSS, Docker Compose y Dokploy.

### Sistema de Inscripción y Cambio de Materias

Proyecto académico orientado a gestionar procesos de inscripción y solicitudes de cambio de materias en un entorno universitario.

Su alcance contempla solicitudes posteriores a la inscripción, revisión por parte del decanato y un flujo de pago simulado.

**Mi responsabilidad:** desarrollo integral de la aplicación, desde la definición de los flujos hasta la implementación de las reglas académicas y la persistencia de la información.

**Enfoque del proyecto:**

- Modelado de procesos y reglas académicas.
- Gestión de solicitudes y sus estados.
- Separación de responsabilidades entre los participantes del proceso.
- Validación y almacenamiento de la información.

### CaféTrazable SV

Sistema para el sector cafetalero salvadoreño con proyección de comercialización a través de CASATIC SV.

Participé como desarrollador Full-Stack, con responsabilidades en la preparación del proyecto, el desarrollo frontend y la puesta en producción.

**Mis principales aportes:**

- Configuración inicial del repositorio y preparación del entorno de despliegue.
- Automatización de la construcción de imágenes de contenedor mediante GitHub Actions.
- Configuración de Docker y Docker Compose para ejecutar la aplicación.
- Continuidad del desarrollo frontend tras la salida del desarrollador responsable de esa área.
- Puesta en producción en un servidor preparado y administrado por mí, utilizando Dokploy.
- Gestión del dominio y de la configuración necesaria para hacer accesible el sistema desde internet.

Esta experiencia me permitió asumir responsabilidades en distintas etapas del producto y dar continuidad al trabajo del equipo hasta su publicación.
